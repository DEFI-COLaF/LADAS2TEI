    1.1. Introduction

    1.1.1. About LADaS

    LADaS, which stands for "Layout Analysis Dataset with SegmOnto," is both a controlled vocabulary and a dataset. It was originally created as part of the COLaF Project (INRIA), before being extended to the ATRIUM Project.

    As a controlled vocabulary, LADaS aims at describing the layout of printed or typewritten textual documents, and their related materials (e.g. posters, manuscripts). It is derived from the preexisting SegmOnto controlled vocabulary, but provides a more detailed description of the page layout by focusing on the graphical representation of elements like paragraphs, headings, tbales, forms, or images.

    The core of the LADaS model is to be able to reconstruct a document from its image into a TEI file.

    1.1.2. About this Document

    This document presents the TEI customisation for LADaS-generated files. It provides explanations for the mapping between the LADaS layout annotations for zone segmentation and the TEI standard as described in the Guidelines.

    Due to the inherent nature of LADaS, modules like "namesdates," through crucial for the encoding of digital scholarly editions, are not included because they go beyond the reconstruction of a document's layout.
